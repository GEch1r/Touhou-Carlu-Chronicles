<h1>东方卡露记 ～ Chronicles of Carlutia</h1>
<h2>Touhou Carlu Chronicles</h2>

<p>Touhou Carlu Chronicles 是一个基于 NeoForge 的 Minecraft 模组包，融合东方 Project 主题内容与冒险、战斗及生存玩法。</p>

[![MIT License][license-shield]][license-url]

<h2>版本信息</h2>

<ul>
  <li>Minecraft：<code>1.21.1</code></li>
  <li>NeoForge：<code>21.1.250</code></li>
  <li>模组包版本：<code>0.0.1</code></li>
  <li>维护团队：<code>TCS-Team</code></li>
</ul>

<h2>使用方式</h2>

<p>本项目使用 <a href="https://packwiz.infra.link/">Packwiz</a> 管理。安装 Packwiz 后，可根据需要使用仓库中的 <code>pack.toml</code> 生成或更新对应的模组包发行文件。</p>

<p>请确保启动器使用上述 Minecraft 和 NeoForge 版本，并在启动前准备好所需的模组文件。</p>

<h2>目录说明</h2>

<ul>
  <li><code>mods/</code>：模组清单</li>
  <li><code>config/</code>、<code>defaultconfigs/</code>：游戏与模组配置</li>
  <li><code>kubejs/</code>、<code>scripts/</code>：脚本与自定义内容</li>
  <li><code>resourcepacks/</code>、<code>shaderpacks/</code>：资源包与光影</li>
  <li><code>datapacks/</code>：数据包</li>
  <li><code>overrides/</code>：需要覆盖到实例目录的文件</li>
</ul>
