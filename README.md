# Touhou Carlu Chronicles

Touhou Carlu Chronicles 是一个基于 NeoForge 的 Minecraft 模组包，融合东方 Project 主题内容与冒险、战斗及生存玩法。

## 版本信息

- Minecraft：`1.21.1`
- NeoForge：`21.1.250`
- 模组包版本：`0.0.1`
- 维护团队：`TCS-Team`

## 使用方式

本项目使用 [Packwiz](https://packwiz.infra.link/) 管理。安装 Packwiz 后，可根据需要使用仓库中的 `pack.toml` 生成或更新对应的模组包发行文件。

请确保启动器使用上述 Minecraft 和 NeoForge 版本，并在启动前准备好所需的模组文件。

## 目录说明

- `mods/`：模组清单
- `config/`、`defaultconfigs/`：游戏与模组配置
- `kubejs/`、`scripts/`：脚本与自定义内容
- `resourcepacks/`、`shaderpacks/`：资源包与光影
- `datapacks/`：数据包
- `overrides/`：需要覆盖到实例目录的文件
